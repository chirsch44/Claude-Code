# Baseball Image Generator ⚾

A simple, interactive website that generates a different baseball image every time you press a button. Perfect for beginners learning web development!

## What This Does

- Displays a beautiful web page with a button
- Each time you click the button, a new baseball image appears
- Images are randomly selected and won't repeat until you've seen them all
- Smooth animations and responsive design

## How to Use

1. **Open the website**: Simply open `index.html` in your web browser
   - Double-click the `index.html` file, or
   - Right-click and choose "Open with" → your browser (Chrome, Firefox, Safari, etc.)

2. **Click the button**: Press the "Generate Baseball" button to see different baseball images

3. **Enjoy**: Click as many times as you want!

## Customization Ideas

Want to make it your own? Try:
- Change the colors in `css/styles.css`
- Add more baseball images to the array in `js/app.js`
- Change "baseball" to another topic (dogs, cats, cars, etc.)
- Add a counter to show how many images you've viewed
- Add sound effects when clicking the button

## Troubleshooting

**Images not loading?**
- Make sure you have an internet connection (images are loaded from online sources)
- Try refreshing the page

**Button not working?**
- Check the browser console for errors (F12 key)
- Make sure all files are in the correct folders
